Run a mesh node on this computer

A node lets others connect through you, extending the mesh.

1. Download the node files:

2. Install Node.js if you don't have it:
nodejs.org → download LTS

3. Open Terminal in the download folder and run:

node server.js

4. Share your node address with neighbors:

ws://YOUR-IP:8765

To connect to another node on startup:
node server.js --peers ws://neighbor-ip:8765
